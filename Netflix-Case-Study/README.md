# Netflix Data Analysis Case Study

Exploratory Data Analysis (EDA) of Netflix movies and TV shows using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Objectives
- Analyze Netflix movies and TV shows
- Explore country-wise content distribution
- Identify popular genres
- Analyze content addition trends
- Study monthly and yearly patterns
