🛒 Walmart Customer Purchase Behavior Analysis

📌 Project Overview

This case study explores customer purchasing behavior using a dataset of approximately 550,000 transactions. It combines Exploratory Data Analysis (EDA) with statistical inference to understand spending patterns across different customer segments.

🎯 Objectives

Analyze customer purchasing patterns across gender and age groups.

Explore purchase distributions and demographic trends.

Apply the Central Limit Theorem and confidence intervals.

Identify meaningful differences in customer spending.

Derive actionable business insights.

🛠️ Tools & Technologies

Python | Pandas | NumPy | Matplotlib | Seaborn | SciPy | Jupyter Notebook

📊 Analysis Techniques

Exploratory Data Analysis (EDA)

Univariate and Bivariate Analysis

Customer Segmentation

Statistical Inference

Confidence Interval Estimation
